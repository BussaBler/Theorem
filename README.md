# Theorem Editor

Theorem is the primary editor and application built on top of the **Axiom Game Engine**. 

Axiom is an internally developed, minimal-dependency engine (utilizing SPIRV-Cross and Shaderc) that handle the shader system. Axiom is included in this repository as a Git submodule.

## Getting Started

Because the engine is a submodule, you must clone this repository recursively to download all required files:

```bash
git clone --recursive git@github.com:YourName/Theorem.git
cd Theorem
